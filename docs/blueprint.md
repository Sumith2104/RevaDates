# **App Name**: MatchMake AI

## Core Features:

- User Profiles: Users can create and edit their profiles, including uploading photos. Form validations for the profile information will be performed to ensure it follows basic validity and formatting.
- User Discovery: Implement a Tinder-style swipeable interface to view other user profiles and express interest (like) or pass.
- Reporting: Allow users to block or report other users for inappropriate behavior.
- Filtering: User preferences and filtering to set things like the range of shown ages or maximum distances
- Profile AID: tool which suggests profile improvements based on what you write about yourself.
- Get Started Page: A 'Get Started' page to onboard new users, with Login and signup button. For signup ask name, phone, dob, email. Email should be verified by OTP that should be sent from SMTP.

## Style Guidelines:

- Background color: Black (#000000) to provide a sleek backdrop.
- Accent color: White (#FFFFFF) for buttons to ensure they are clearly visible and easily tappable.
- Body and headline font: 'Inter' sans-serif, chosen for its clean and modern aesthetic, is used for both headings and body text, ensuring readability and a contemporary feel.
- Use simple, modern icons from a set like Material Icons to maintain consistency and clarity.
- Responsive grid-based layout using Tailwind CSS for seamless adaptation across devices.
- Subtle transition effects for UI elements and interactions to enhance user experience without being intrusive.
